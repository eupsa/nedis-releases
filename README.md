Aqui ficam os **instaladores e as atualizações** do aplicativo desktop do Nedis.

Site oficial: [nedis.com.br](https://nedis.com.br)

> Se o arquivo do seu sistema ainda não aparecer na última versão, ele ainda não foi publicado.

## Como instalar

**Windows:** execute `Nedis-Setup.exe`, aceite a licença e conclua a instalação (ela pede permissão de administrador).

- O Windows pode mostrar "O Windows protegeu o computador". Clique em **Mais informações** e depois em **Executar assim mesmo**. Baixe sempre deste repositório ou do site oficial.

**macOS:** abra o `Nedis.dmg` e arraste o app para a pasta Aplicativos.

**Linux:** no AppImage, dê permissão de execução (`chmod +x Nedis.AppImage`) e abra. No `.deb`, instale com `sudo apt install ./Nedis.deb`.

## Atualizações

O app se atualiza sozinho: procura versões novas ao abrir e a cada poucas horas, baixa em segundo plano e avisa quando está pronta. Você escolhe **Reiniciar para atualizar** no ícone da bandeja ou deixa para instalar quando fechar o app.

Você não precisa baixar nada de novo para atualizar. Use os instaladores daqui apenas para instalar pela primeira vez ou reinstalar.

## Ajuda

- O app não atualiza: confirme que há internet e reinstale pelo link acima.
- Dúvidas e suporte: veja o [site](https://nedis.com.br). Não publique dados pessoais, senhas ou códigos de verificação neste repositório.
